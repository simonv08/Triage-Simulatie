\# Over dit project



Ik bouw een webpagina die resultaten toont uit een eigen API.



\## De API



Draait op http://localhost:5050



| Methode | Adres | Geeft terug |

|---|---|---|

| GET | /resultaten | alle resultaten |

| GET | /resultaten/{id} | één resultaat, of 404 |

| GET | /resultaten/top/{oefening} | de vijf snelste tijden |



GET /resultaten geeft dit terug:



{

&#x20; "resultaten": \[

&#x20;   { "cursist": "Daan", "oefening": "klimmen",

&#x20;     "seconden": 94.20, "fouten": 1, "id": 1 }

&#x20; ]

}



De veldnamen zijn exact zoals hierboven, met kleine letters.



\## Hoe ik wil dat je code schrijft



\- Gewone HTML, CSS en JavaScript. Geen React, geen Vue, geen build.

\- Gebruik fetch, geen externe bibliotheken.

\- Nederlandse tekst op het scherm, Engelse namen in de code.

\- Toon altijd iets als er een fout is of als de lijst leeg is.



\## Wat je niet doet



\- Verzin geen endpoints die hierboven niet staan.

\- Verzin geen velden die niet in de JSON zitten.

\- Heb je iets nodig dat ik niet gegeven heb, vraag het dan.
